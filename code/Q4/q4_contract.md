# 第四问计算契约

继承第三问的热质传递框架和环境边界，但使用附件2的半径 (R(t)) 与附录4物性。药材材料点以 ξ=r/R(t) 表示，ξ=0 为中心、ξ=1 为表面。干基含水率随材料运动，均匀径向收缩速度与坐标变换项抵消，归一化控制方程为

\[
\rho(C)c_p(C)T_t=\frac{1}{R(t)^2\xi}\partial_\xi(\xi k(C)T_\xi),\qquad
C_t=\frac{1}{R(t)^2\xi}\partial_\xi(\xi D(C,T)C_\xi).
\]

Robin边界变为 \(-kT_\xi/R=h(T_s-T_\infty)\)、\(-DC_\xi/R=h_m(C_s-C_\infty)\)。半径附件2分段线性插值，数据末点后保持末值。Kirchhoff势用于C界面通量，BDF自适应时间积分，网格和容差收敛后停止。

输出：表6每6小时、固定物理距离0/0.5/1/1.5 cm及动态表面；result4每60 s，固定物理距离0..2 cm每0.1 cm，超出当前R(t)填空，并附动态表面列。烘干时长按全部材料点含水率低于0.15判定。
