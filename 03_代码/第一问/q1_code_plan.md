## 计算步骤

构造包含 r=0、r=R、z=0、z=L/2 的节点中心网格及控制体边界。中心面和对称中面为零面积或零通量。内部面用对称调和导通系数，外侧/端面为真实边界节点 Robin 通量，角点同时计算两张边界面。组装后内部交换通量对总量贡献必须抵消。

温度容量为 rho cp V，水分容量为 V（均匀固定干物质密度消去的有效浓度方程）。温度线性且独立，水分非线性依赖当前 C。先用隐式 Euler 半步启动，再采用 CN；每步在新时间层更新 D 并迭代至收敛，必要时缩短时间步。保存实际步长、迭代次数、残差、拒绝/恢复情况。

一维基线仅保留径向网格，其他数值规范、物性、初值与环境保持一致。共享输出时间和半径位置。二维中截面生成官方矩阵；二维全域状态用于端面和守恒诊断。

在同一比较网格上报告网格加密及时间步减半导致的温度最大绝对变化、含水率最大绝对变化，至少覆盖全部指定输出时刻。重点监测初期表面与100 s时刻，不把1 s输出间距当作空间/时间误差证明。计算网格和主步长由实际运行性能、收敛证据决定，不预写通过或固定精度结论。

## 守恒与可比指标

二维全域可由半域结果乘2；若只报告平均量，系数抵消。水分总量的绝对 kg 值涉及干物质密度解释，应明确 rho_d 是否取 rho/(1+C0)，并不得把 ∫C dV 的单位写成 kg。至少验证浓度体积分变化与传质边界通量积分相等，报告其归一化相对误差。

热量变化为 ∫rho cp (T-T0)dV，与累积外表面净传热量比较。边界时间积分必须使用与 Euler/CN 一致的权重，不能用另一种粗输出积分制造伪差异。

比较指标必须同单位、同空间位置、同时间。二维中截面与一维相似不能代表全域或体积平均相同。无内部观测，不报告RMSE预测精度或虚构实验拟合优度。

## 命名审查检查

- INPUT_SOURCE_MATCH：来源哈希、常数、单位、0—1800 s边界。
- PDE_CONSERVATIVE：div(D grad C)、轴对称体积、内部面反对称、中心/角点。
- ROBIN_SURFACE：表面节点与局部物性、侧面和端面符号。
- NONLINEAR_TIME：启动格式、实际收敛残差、CN当前层系数。
- MASS_HEAT_BALANCE：总量与外通量平衡。
- PHYSICAL_RANGE：有限性、C非负、T合理范围，不依赖事后裁剪。
- GRID_TIME_CONVERGENCE：实际加密结果及适用精度。
- BASELINE_COMPARABLE：同参数/同边界/同输出，量化端部影响。
- TEMPLATE_COMPLETE：1800×21×2结果，7×5表对应，四位小数，无缺失。
- REPRODUCIBLE：脚本、依赖、参数、输入输出与证据路径完整。

当前没有需激活的独立 fallback。run_summary 的 fallback_id、condition 为 null，observed=false，并说明数值恢复仍属主求解器。不使用随机算法，random_seed=null，说明确定性PDE；不要编造实际使用的随机种子。

Python 依赖预期 numpy、scipy，读输入用csv；表格输出遵守 spreadsheet 技能。运行时长以实际 execution_time_seconds 记录，不作未经运行的承诺。
